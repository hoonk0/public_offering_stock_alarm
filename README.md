# public_offering_stock_alarm

38커뮤니케이션(38.co.kr) 크롤링 기반 공모주 청약 알림 봇.

## 주요 기능

- **자동 알림** (Telegram)
  - 매월 1일 09:00 — 그 달의 청약 예정 종목 다이제스트
  - 청약 첫날 08:30 — 4대 지표 + 1~5등급 + 마통 분석
  - 청약 둘째날 15:00 — 마감 임박 리마인더
- **명령어 응답**
  - `/이번주`, `/다음주` — 청약 종목 + 등급 + 예상 수익
  - `/N월수익률` — 그 달 상장 종목들의 첫날 수익률
  - `/1등급` ~ `/5등급` — 등급별 첫날 수익률 통계
  - `/help` — 전체 명령어

## 5단계 등급 시스템 (2025-2026 119종목 분석 기반)

| 등급 | 점수 | 평균 시초가 수익률 | 마통 청약 권장 |
|---|---|---|---|
| 💎 1등급 | 12 (만점) | +247% | ✅ 풀투자 강추 |
| 🔥 2등급 | 10-11 | +201% | ✅ 풀투자 가능 |
| ✅ 3등급 | 6-9 | +87% | ⚠️ 신중하게 |
| ⚖️ 4등급 | 4-5 | +49% | 균등배정만 |
| ❌ 5등급 | 0-3 | +12% | 청약 비추 |

## 4대 지표 (가중치 적용)

- 기관 수요예측 경쟁률 (×1, max 3점)
- **의무보유확약 (×2, max 6점)** — 가장 강한 신호 (Pearson +0.682)
- 유통가능물량 (×0, 신뢰도 낮음)
- 공모가 결정 위치 (×1, max 3점)

## 라즈베리파이 배포

```bash
git clone git@github.com:hoonk0/public_offering_stock_alarm.git ~/ipo_bot
cd ~/ipo_bot
cp .env.example .env
nano .env  # 텔레그램 토큰/챗ID 입력
bash setup_pi.sh  # venv + 패키지 + systemd 자동 설정
```

## 기술 스택

- Python 3.11+
- requests + BeautifulSoup4 (38커뮤 크롤링, EUC-KR)
- APScheduler (cron 스케줄러)
- SQLite (중복 발송 방지 + 등급 캐시)
- python-dotenv
